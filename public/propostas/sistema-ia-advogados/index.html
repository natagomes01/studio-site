Sistema IA para Advogados

Uma solução de IA para automação de atendimento ao cliente e gestão processual em escritórios de advocacia. O problema central: advogados gastam tempo excessivo respondendo clientes sobre status de processos, gerando ansiedade e atrito desnecessário. Este documento consolida o escopo do MVP, o briefing técnico e as condições comerciais para aprovação dos sócios investidores.

01 — Contexto e objetivo

Por que este produto

A solução proposta simplifica a comunicação entre escritório, cliente e sistema judiciário, reduzindo carga operacional e melhorando a experiência do cliente final. Não é apenas comunicação — é simplificação e eficiência: o cliente recebe informação útil e simplificada, o advogado recebe informação robusta para decidir, e o escritório economiza tempo de atendimento.

A estratégia de entrada é começar pequeno: notificações simples, sem histórico completo do processo e sem armazenar dados sensíveis na primeira versão. Isso reduz complexidade de cibersegurança e mantém o custo do MVP baixo. O modelo de receita previsto é assinatura mensal por escritório, com possível componente de pay-per-message.

O produto atende dois públicos distintos — advogados solo com alto volume de clientes simples, e grandes escritórios com necessidade de controladoria — e pode oferecer módulos diferentes conforme a necessidade de cada um.

02 — Decisões finais acordadas

Escopo do MVP: três módulos

O time decidiu focar em um produto com três módulos principais, escalando depois para controladoria e para outros públicos.

01

Atendimento ao cliente via WhatsApp

  • Disparo automático de notificação quando há movimentação processual
  • Mensagens personalizadas — nunca genéricas — explicando o que aconteceu
  • Integração com a API aberta do WhatsApp Business
  • Advogado revisa e autoriza a mensagem antes do envio ao cliente
02

Tradução de decisões judiciais

  • Conversão de linguagem jurídica complexa em explicação simples
  • Tabela de códigos para mapear tipos de decisão padrão
  • Exemplo: "processo indeferido" vira explicação clara do que isso significa
  • Fallback para tabela padrão se a IA falhar ou tiver baixa confiança
03

Plataforma própria

  • Aplicativo ou web, para não ficar refém de mudanças de política do WhatsApp
  • Alternativa de comunicação além do WhatsApp
  • Push notifications quando há movimentação processual
  • Preferível ao WhatsApp a médio prazo, mantendo o WhatsApp como canal inicial
03 — Além do atendimento

Controladoria e integração judicial

Para escritórios com grande volume de processos, um módulo de controladoria automatiza a triagem: a IA sugere fluxo com base em protocolos do escritório — sem decidir sozinha — e a equipe processa múltiplos fluxos em paralelo com essas sugestões, mantendo histórico de movimentações em Markdown para consulta rápida.

Do lado judicial, o sistema filtra movimentações irrelevantes e foca em decisões e despachos importantes, acessando a API pública de comunicações processuais do CNJ. A consulta por número de OAB recupera todos os processos do advogado; documentos publicados no diário oficial ficam disponíveis com cerca de um dia de delay, e o limite de 10 mil consultas mensais da API é suficiente para o volume esperado do MVP.

Antes de fechar a arquitetura

  • CNJ Qual a frequência de atualização — tempo real, hora em hora, diária? Como lidar com o delay entre publicação no diário e disponibilidade na API?

05 — Duas estratégias de MVP

API aberta vs. API oficial do tribunal

A recomendação é começar pela opção A para prototipar e validar com o cliente-investidor, migrando para a B quando o produto precisar escalar.

Recomendada para o MVP

A · API aberta do CNJ

Fase inicial, prototipagem, validação com cliente-investidor

  • Sem custo de acesso aos dados
  • Rápido para validar o conceito
  • Sem dependência de aprovação de tribunal
  • Limite de 10.000 consultas por mês
  • Delay entre publicação e disponibilidade
  • Nem todo documento vem com teor completo
  • Não cobre segredo de justiça
Fase de escala

B · API oficial do tribunal

Após validação com cliente, para escalar

  • Acesso em tempo real, documentos completos
  • Sem limite de consultas
  • Suporta segredo de justiça
  • Requer aprovação do tribunal
  • Pode ter custo de acesso
  • Integração mais complexa — API diferente por estado
  • +40–60h de desenvolvimento adicional

07 — Investimento e condições comerciais

O pacote fechado deste MVP

O que está sendo vendido é o pacote completo do MVP — não horas avulsas, e não os módulos de controladoria ou plataforma própria descritos mais acima, que ficam para uma fase seguinte.

Incluído neste pacote

  • Integração com a API pública do CNJ, filtrada por OAB
  • Processamento por IA: resumo automático de decisões e despachos, com tabela padrão como fallback
  • Notificação ao advogado via WhatsApp, com aprovação antes do envio ao cliente
  • Notificação ao cliente final via WhatsApp, com mensagem personalizada
  • Banco de dados do MVP: advogados, clientes, processos, movimentações e logs de envio
  • Dashboard interno de acompanhamento: pendências, histórico e status de entrega
  • Acompanhamento e ajuste ao longo das 9 semanas de desenvolvimento

Fora deste pacote

  • Módulo de controladoria — triagem automatizada de processos e sugestão de fluxo
  • Plataforma própria (aplicativo ou web dedicado) — o MVP roda inteiramente sobre WhatsApp
  • Migração para a API oficial do tribunal (Opção B) — fica para a fase de escala
  • Custos variáveis de WhatsApp Business e de tokens de IA em produção, após o período do MVP

09 — Questões em aberto

Decisões de produto para amadurecer

Não bloqueiam a aprovação do pacote acima — são decisões do produto final (para os advogados clientes) que o time vai amadurecer ao longo do desenvolvimento e da fase de escala.

  • 01

    TAM e ticket médio

    Quantos escritórios de advocacia no Brasil poderiam usar essa solução, e qual é o ticket mensal viável frente à concorrência — JusBrasil cobra R$ 29,90–39,90/mês?

  • 02

    Modelo de precificação

    Assinatura fixa com pay-per-message, ou assinatura com limite de mensagens embutido? Isso muda a estrutura de custo do WhatsApp Business API.

  • 03

    Frequência de polling da API CNJ

    A cada hora, a cada seis horas, diariamente? A escolha impacta diretamente custo de infraestrutura e latência da notificação ao cliente.

  • 04

    Escala inicial do MVP

    Com o limite de 10 mil consultas mensais, dá para cerca de 100 advogados com 100 processos cada. Com quantos advogados o time quer começar?

  • 05

    Custo do WhatsApp Business oficial

    Entre R$ 0,50 e R$ 1,00 por mensagem — com 500 mensagens/dia isso fica em R$ 7.500–15.000/mês. Vale usar a API oficial já no MVP ou começar pela aberta?
